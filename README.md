# 本科职业发展模拟器

一个把大学四年压进一局二十多分钟的文字模拟游戏。Windows 单机，双击就能玩。

你是一个刚考完高考的学生。四年里有 **16 个学期**、**38 个行动点**、**6 条毕业赛道**、
**8 个大专业类**、**571 张行动卡**（其中 210 张是分阶梯的真实竞赛）、**60 个技能树节点**、
**8 类爱好**、**21 个随机事件**。你会变成什么样，取决于你怎么花掉那 38 个点。

---

## 直接玩

去 `dist/` 拿 `本科职业发展模拟器-1.0.0-pc.zip`，解压后双击里面的 exe。

---

## 玩法

### 一局的结构

```
标题 → 选起步线（5 选 1）→ 选大专业（8 选 1）→ 序章 2 问
    → 16 个学期循环：
         每学期分配行动点 → 确认 → 看结算 → 可能撞上事件或关键抉择
    → 结局（6 类 + 兜底）
```

### 行动点与收益

每学期给的行动点不一样，前重后轻：大一上 4 点，中段 3 点，大四上 2 点，大四下 1 点，
加起来 **38 点**。这是全游戏唯一的资源。

收益有三条规则同时在起作用：

1. **同一张卡重复投会递减**。第一次给满额，之后按 0.75 打折。
2. **同一方向换不同的卡投，不递减**。这是正解 —— 想提升绩点，就在"课业精进""期末冲刺"
   "专业课死磕"之间换着来，而不是死磕一张。
3. **单学期同一属性投超过 2 点会吃疲劳**。身体和心态都要还债。

所以"在某条路上投入越多收益越高"是真的，但正确做法是**换手段**，不是刷同一件事。

### 六条赛道

| 赛道 | 靠什么上岸 |
|---|---|
| 保研 | 绩点 + 科研 + 英语，加上前六学期的排名和竞赛加分 |
| 考研 | 应试能力 + 绩点 + 英语，大四上的一次初试 |
| 进厂就业 | 实习 + 作品集（或人脉），秋招拿到 offer |
| 考公选调 | 应试能力 + 组织影响力，党员身份是硬条件 |
| 出国留学 | 英语（硬门槛）+ 绩点 + 科研或实习背景 |
| 科研深造 | 科研素养 + 论文成果，走学术路线 |

**技能树**是主要的可视化：6 列对应 6 条赛道，每列 8 个节点，从"基线"一路到"大成"。
另外有 8 个跨赛道共享节点（国家级竞赛奖项、学术论文发表、英语硬通货……）和 4 个专业专属节点。
节点解锁后会给你属性和收益加成，还会授予 flag（比如"推免资格"）——这些 flag 是结局的必需品。

技能树同时提供**百分比条视图**：每条赛道一行，显示"已解锁 N / 16"和完成度。

### 竞赛体系（这版的重点）

竞赛不只有"互联网+"。每个大专业类有自己的竞赛池，共 **73 个真实竞赛**、**210 个阶梯卡**。

- 每个专业能看见 **22-56 个**竞赛，其中 **5-10 个是专属**的。
- 阶梯是 **校赛 → 省赛 → 国赛 → 国际赛**，不能跳级。越高阶收益越大，也越可能空手而归。
- 大二上可以选 **最多 2 个主攻**，主攻的收益 ×1.25，还能带上指导教师。

举几个例子：计算机类打 CCPC、蓝桥杯、天梯赛、电赛；机械类打成图大赛、机械创新设计、
工程训练；土木与海洋工程类打结构设计、水利创新设计、海洋航行器设计；医药类打临床技能、
药学实验技能；人文社科类打外研社国才杯、模拟法庭、广告艺术大赛。

**计算机的学生看不到水产技能大赛，水产的学生看不到蓝桥杯。**

### 起步线

5 条起步线的**属性点总量是一样的**，差别在分布和已经打开的门：

| 起步线 | 开局就有的东西 | 代价 |
|---|---|---|
| 竞赛大佬 | 直接进实验室的资格，科研和作品起点高 | 人脉和组织影响力是零 |
| 干部苗子 | 入党申请和学生会干部节点，人脉高 | 绩点和外语只是中游 |
| 小镇做题家 | 开局绩点最高，应试能力强 | 英语、人脉、领导力都弱 |
| 文艺特长 | 稳定的心态和人脉，简历起点 | 绩点偏低 |
| 标准新生 | 身体和心态都不错，没有短板 | 没有捷径 |

### 爱好

8 大类：运动健身 / 艺术创作 / 音乐 / 游戏与电竞 / 阅读与思辨 / 影视与动漫 / 美食与生活 /
志愿与公益。每投入一次给 10 点经验，门槛是 20/50/90/140/200，对应 Lv1-Lv5。

升级给属性、给 flag、也会解锁专属事件。**练到 Lv5「精通」会把爱好变成技能树上的正式节点**
——这是一局里很难达成的事，得投 20 次。

侧栏只显示**已经投入过**的爱好，避免刷屏；完整列表在「爱好」页。

## 开发

### 环境

需要 Windows + PowerShell。其余依赖脚本会自动处理。

```powershell
# 1. 装 Ren'Py SDK（约 155MB，会解压到 .renpy-sdk/）
powershell -File tools/setup_renpy.ps1

# 2. 装测试依赖（装进 .tools/pylibs，不动系统 Python）
python -m pip install --target .tools/pylibs pytest coverage

# 3. 一把梭：pytest + lint + 界面走查
powershell -File tools/check_all.ps1

# 4. 打包
powershell -File tools/build.ps1
```

### 单独跑

| 命令 | 作用 |
|---|---|
| `tools/pytest.ps1` | 纯 Python 内核测试（182 条） |
| `tools/lint.ps1` | Ren'Py 脚本静态检查 |
| `tools/font_check.ps1` | 字体覆盖检查（防止界面出现豆腐块） |
| `tools/run_tests.ps1` | 界面走查 + 截图到 `tests/screenshots/`（14 张） |
| `tools/build.ps1` | 打包到 `dist/`，并自动解包校验产物 |
| `python tools/simulate.py --games 3000 --by-major` | 平衡模拟：结局分布、节点可达性 |
| `python tools/debug_run.py --strategy 考研` | 打印一局的完整过程，排障用 |

### 工程结构

```
game/
├─ core/            纯 Python 数值内核，不依赖 renpy，可单独测试
│  ├─ config.py     所有平衡旋钮（调参只改这个文件）
│  ├─ state.py      数据模型 + 存档序列化
│  ├─ effects.py    所有数值公式的唯一实现处
│  ├─ majors.py     8 个大专业类
│  ├─ contests.py   73 个竞赛 + 阶梯表
│  ├─ actions.py    571 张行动卡
│  ├─ skilltree.py  60 个技能树节点
│  ├─ hobbies.py    8 类爱好 × 6 级
│  ├─ events.py     21 个随机事件
│  ├─ endings.py    结局判定
│  ├─ starts.py     5 条起步线 + 序章 + 4 个大四关键抉择
│  └─ engine.py     GameEngine：UI 层唯一入口
├─ bridge.rpy       Ren'Py 与内核之间的桥 + 全局界面状态
├─ theme.rpy        配色、字号、Style、复用组件
├─ screens_game.rpy 主玩法界面 + 结算/事件/抉择浮层
├─ screens_tree.rpy 技能树 / 竞赛 / 爱好 / 属性
├─ screens_extras.rpy 开场 / 选起步线 / 选专业 / 设置 / 结局
├─ script.rpy       主流程
└─ testcases.rpy    自动化走查 + 截图
```

**分层原则**：所有数值逻辑在 `core/` 里，UI 只做渲染和点击分发。
所以平衡模拟和 182 条测试都能在**不启动 Ren'Py** 的情况下跑完（2.5 秒）。

### 调参

平衡旋钮集中在 `game/core/config.py`：

- `AP_BY_SEMESTER` — 每学期行动点（改完必须重跑 simulate，门槛要重新标定）
- `EFFECT_BASE` / `REPEAT_DECAY` / `RARITY_MULT` — 收益公式
- `FATIGUE_*` — 疲劳系统
- `ENDING_GATES` / `ENDING_ALTS` / `ENDING_FLAGS` — 结局门槛
- `CONTEST_TIER_*` — 竞赛阶梯
- `HOBBY_LEVEL_THRESHOLDS` — 爱好曲线

改完跑 `python tools/simulate.py --games 3000` 看结局分布是否还在 5%-45%。

### 内容写作

写新内容之前先读 `docs/CONTENT_SPEC.md`（内容作者契约）和 `docs/DESIGN.md`（设计文档）。
内容文件都在导入时自校验，写错会立刻报错并指出问题，不会拖到运行时。

## 已知边界

- 只做了 Windows 包，Mac/Linux 没打包（Ren'Py 本身支持，改 `tools/build.ps1` 的 `-Package` 就行）。
- 没有音乐音效，接口留着。
- 没有成就系统，只有结局标签。
- 学校名是抽象的"某 985 大学"，专业名可以开局自选。要改成实名，改 `game/core/config.py` 的
  `GameConfig.school_name` 默认值。
