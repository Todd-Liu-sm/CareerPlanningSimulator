# 本科职业发展模拟器

一个把大学四年压进一局二十多分钟的文字模拟游戏。Windows 单机，双击就能玩。

你是一个刚考完高考的学生。四年里有 **8 个学期**、**24 个行动点**、**6 条毕业赛道**、
**8 个大专业类**、**166 张行动卡**（其中 20 张是分阶梯的竞赛卡）、**30 个技能树节点**、
**8 类爱好**、**21 个随机事件**。你会变成什么样，取决于你怎么花掉那 24 个点。

行动卡按 **12 个分类折叠**（学业 / 科研 / 外语 / 实习就业 / 考试备考 / 社交人脉 /
组织与党团 / 作品与项目 / 爱好 / 运动与休息 / 竞赛 / 心态与调整），点标题展开收起，
不用在一百多张卡里翻。

---

## 直接玩

去 `dist/` 拿 `本科职业发展模拟器-1.0.0-win64.zip`，**解压后双击里面的 exe**。

绿色包，不写注册表、不装运行库、不联网，删掉文件夹就等于卸载。
存档不在这个文件夹里（在系统的用户目录下），所以换个位置解压也能接着玩。

> **为什么没有 setup.exe**：第一版做过一个 C# 自解压安装程序，但它是个未签名的
> 可执行文件，正是 Windows 和各种安全软件最爱盘问的形态 —— 玩家还没进游戏就先撞上
> 安全提示。绿色包解压即玩，中间没有任何环节，所以把安装程序撤了。

## 玩法

### 一局的结构

```
标题 → 选起步线（5 选 1）→ 选大专业（8 选 1）→ 序章 2 问
    → 8 个学期循环：
          每学期分配行动点 → 确认 → 看结算 → 可能撞上事件或关键抉择
    → 大四下把行动点花完 → 结局（6 类 + 兜底）
```

**大四下是一个正常可玩的学期**，没有额外的收尾弹窗：行动点花完的那一瞬间，
结局按属性和技能树直接判定。以前那里挂着一个「结果陆续出来了」的抉择页，
已经按玩家要求删掉了 —— 它会让大四下的 2 个行动点永远花不出去。

**存档**：每进入一个新学期都会自动存档，也可以随时手动存到 12 个槽位。
存档写在 Ren'Py 的用户目录里，关掉游戏不会丢。

### 行动点与收益

每学期 3 个行动点，四年共 **24 点**。大一上多给 1 点（可能性最多的一学期），
大四下少 1 点（在等结果、写毕设）。这是全游戏唯一的资源。

收益有三条规则同时在起作用：

1. **同一张卡重复投会递减**。第一次给满额，之后按 0.75 打折。
2. **同一方向换不同的卡投，不递减**。这是正解 —— 想提升绩点，就在「认真上课」
   「期末冲刺」「整理笔记」之间换着来，而不是死磕一张。
3. **单学期同一属性投超过 3 点会吃疲劳**。身体和心态都要还债。

所以「在某条路上投入越多收益越高」是真的，但正确做法是**换手段**，不是刷同一件事。

### 疲劳：这一版真正的约束

疲劳**按行动点计价**，所以「疯狂卷」是有代价的：

| 一学期的花法 | 疲劳变化 | 能撑多久 |
|---|---|---|
| 3 点全干活 | +10 | 硬扛 4 个学期就撞惩罚线（50） |
| 2 干活 + 1 休息 | −4 | 可以一直维持 |
| 1 干活 + 2 休息 | −18 | 状态越攒越好 |

疲劳到 **50** 所有正收益打八折，到 **80** 会额外扣心态。所以你必须定期安排休息，
不能一路卷到底 —— 但休息也要花行动点，这就是取舍。

带 `休息 / 娱乐 / 运动 / 爱好` 标签的行动都算休息。

### 六条赛道

| 赛道 | 靠什么上岸 |
|---|---|
| 保研 | 绩点 + 科研 + 英语，三条腿都要 |
| 考研 | 应试能力（或绩点 + 英语），大四的那次初试 |
| 进厂就业 | 实习（或人脉 + 作品集），秋招拿到 offer |
| 考公选调 | 应试能力 + 组织影响力，党员身份是硬条件 |
| 出国留学 | 英语（硬门槛）+ 绩点，或英语 + 科研背景 |
| 科研深造 | 科研素养，或科研 + 论文成果 |

「该定方向了」这个抉择给**六条赛道各留一个入口**，外加"两手都抓"。

**门槛是按"必须专精"标定的，不能既要又要。** 24 个行动点分给两条线时每条最多
拿 12 张卡，而门槛顶到了"该属性最好的 8 张卡之和" —— 想同时满足两条线就得
两条各投满，24 点不够。实测"不带目标的均衡打法"平均只命中 **0.05** 条门槛。
所以开局想清楚往哪走，比什么都重要。

**技能树**是主要的可视化：6 列对应 6 条赛道，每列 4 个节点，从「基线」到「大成」。
另外有 6 个跨赛道共享节点（竞赛获奖、英语硬通货、学生干部、身体是本钱、心态不倒、
学术论文发表）。节点解锁后会给你属性和收益加成，还会授予 flag（比如「推免资格」）
—— 这些 flag 是结局的必需品。

技能树同时提供**百分比条视图**：每条赛道一行，显示完成度。

### 结局怎么定

**没有"最后一次判定"了。** 大四下把行动点花完，结局按属性 + 技能树直接算：

```
一条赛道命中  =  它自己那条链上的 capstone 节点解锁了（flag）
                且 它的门槛组里有一组全过（ENDING_GATES / ENDING_ALTS）
```

每条赛道都有两条走法（比如留学可以是「英语 32 + 绩点 14」或者
「英语 24 + 科研 26」），所以不会出现"只有一种解"的死局。

**你在大三上「该定方向了」选的那条路会排在结局判定的最前面** —— 否则一个顺手
把绩点刷高的人，无论一路在准备什么，都会因为保研门槛也被满足而被判成保研，
定方向那一步就白选了。

结局页会把两者分开写：

```
你走通的路
▶ 考研上岸  标准路线  绩点 28 ・ 外语 34 ・ 应试 33
属性上也够得着、但没走的路
・ 考公上岸  选调路线  应试 33 ・ 影响力 36
```

一个把绩点、英语、科研都顶满的人确实同时够得着三条线 —— 那是真的，
但他只走了一条，页面就这么写。

### 竞赛体系

竞赛**只按大类划分**，不写具体比赛名：**科研类 / 工程类 / 商科类 / 人文类 / 综合类**，
每类 **校赛 → 省赛 → 国赛 → 国际赛** 四个阶梯，共 **20 张阶梯卡**。

- 不同专业看得见的大类不同（商科类只有经管、人文、计算机、理科能报；
  工程类文科报不了），综合类对所有人开放。
- **阶梯必须赢下来才能往上打**：校赛没拿奖，省赛就不会出现。
- 越高阶收益越大，也越可能空手而归。
- 大二上可以选 **最多 2 个主攻**，主攻的收益 ×1.25。

### 起步线

5 条起步线的**属性点总量是一样的**，差别在分布和已经打开的门：

| 起步线 | 开局就有的东西 | 代价 |
|---|---|---|
| 竞赛大佬 | 直接进实验室的资格，科研和作品起点高 | 人脉和组织影响力是零 |
| 干部苗子 | 入党申请和学生会干部节点，人脉高 | 绩点和外语只是中游 |
| 小镇做题家 | 开局绩点最高，应试能力强 | 英语、人脉、领导力都弱 |
| 文艺特长 | 稳定的心态和人脉，简历起点 | 绩点偏低 |
| 标准新生 | 身体和心态都不错，没有短板 | 没有捷径 |

### 爱好

8 大类：运动健身 / 艺术创作 / 音乐 / 游戏与电竞 / 阅读与思辨 / 影视与动漫 / 美食与生活 /
志愿与公益。每投入一次给 15 点经验，门槛是 **15 / 45 / 75 / 120**，对应 Lv1-Lv4。
练满一个爱好要 8 次行动 —— 24 个行动点里这是很奢侈的事，所以是刻意的长线投入。

**爱好卡从第 1 学期到第 8 学期一直都在**，反复投同一张就一路升级；
卡上直接写着当前等级和"再投几次升级"。升级给属性、给 flag、也会解锁专属事件。
侧栏只显示**已经投入过**的爱好，避免刷屏；完整列表在「爱好」页。

### 两组数值：结局属性 vs 参考状态

**结局属性（10 项）**决定你能走哪条路，参与结局门槛和技能树门槛。

**参考状态（4 项）**是幸福感 / 自信 / 社交满意度 / 生活状态，**与结局无关**，
初始 50、可以涨也可以跌，只是让你看到这四年过得怎么样：

- 运动、休息、爱好推高生活状态和幸福感
- 社交、社团推高社交满意度
- 熬夜、外卖、一直硬扛会往下掉
- 爱好每升一级额外回 4 点疲劳

两类在界面上**分开显示**（左栏是结局属性，右栏单独一块"参考状态"），
避免你以为它们也要凑。

## 开发

### 环境

需要 Windows + PowerShell。其余依赖脚本会自动处理。

```powershell
# 1. 装 Ren'Py SDK（约 155MB，会解压到 .renpy-sdk/）
powershell -File tools/setup_renpy.ps1

# 2. 装测试依赖（装进 .tools/pylibs，不动系统 Python）
python -m pip install --target .tools/pylibs pytest coverage

# 3. 一把梭：pytest + lint + 字体 + 存档 + 界面走查
powershell -File tools/check_all.ps1

# 4. 打包
powershell -File tools/build.ps1
```

### 单独跑

| 命令 | 作用 |
|---|---|
| `tools/pytest.ps1` | 纯 Python 内核测试（210 条） |
| `tools/lint.ps1` | Ren'Py 脚本静态检查 |
| `tools/font_check.ps1` | 字体覆盖检查（防止界面出现豆腐块） |
| `tools/test_save.ps1` | 真 Ren'Py 存档/读档往返校验（起两次进程） |
| `tools/run_tests.ps1` | 界面走查 + 截图到 `tests/screenshots/` |
| `tools/run_tests.ps1 -EndingOnly` | 只拍结局页（13_ending.png） |
| `tools/build.ps1` | 打包到 `dist/`（绿色包 + zip），并自动解包校验产物 |
| `python tools/simulate.py --games 3000 --by-major` | 平衡模拟：结局分布、节点可达性 |
| `python tools/gen_actions.py` | 重新生成 `game/core/actions.py`（改内容表之后跑） |
| `python tools/check_font_coverage.py` | 扫描所有会被渲染的字符串，找缺字 |

### 工程结构

```
game/
├─ core/            纯 Python 数值内核，不依赖 renpy，可单独测试
│  ├─ config.py     所有平衡旋钮（调参只改这个文件）
│  ├─ state.py      数据模型 + 存档序列化
│  ├─ effects.py    所有数值公式的唯一实现处
│  ├─ majors.py     8 个大专业类
│  ├─ contests.py   5 个竞赛大类 × 4 阶梯
│  ├─ actions.py    166 张行动卡（由 tools/gen_actions.py 生成）
│  ├─ skilltree.py  30 个技能树节点
│  ├─ hobbies.py    8 类爱好 × 5 级
│  ├─ events.py     21 个随机事件
│  ├─ endings.py    结局判定
│  ├─ starts.py     5 条起步线 + 序章 + 3 个关键抉择（第 5/6/7 学期）
│  └─ engine.py     GameEngine：UI 层唯一入口
├─ bridge.rpy       Ren'Py 与内核之间的桥 + 全局界面状态
├─ theme.rpy        配色、字号、Style、复用组件
├─ save_support.rpy 存档槽位读写、自动存档、续玩
├─ screens_save.rpy 存档 / 读档界面
├─ screens_game.rpy 主玩法界面 + 结算/事件/抉择浮层
├─ screens_tree.rpy 技能树 / 竞赛 / 爱好 / 属性
├─ screens_extras.rpy 开场 / 选起步线 / 选专业 / 设置 / 结局
└─ script.rpy       主流程
```

**分层原则**：所有数值逻辑在 `core/` 里，UI 只做渲染和点击分发。
所以平衡模拟和 197 条测试都能在**不启动 Ren'Py** 的情况下跑完（1 秒）。

### 调参

平衡旋钮集中在 `game/core/config.py`：

- `AP_BY_SEMESTER` — 每学期行动点（改完必须重跑 simulate，门槛要重新标定）
- `REPEAT_DECAY` / `RARITY_MULT` — 收益公式
- `FATIGUE_*` — 疲劳系统
- `ENDING_GATES` / `ENDING_ALTS` / `ENDING_FLAGS` — 结局门槛
- `CONTEST_TIER_*` — 竞赛阶梯
- `HOBBY_LEVEL_THRESHOLDS` — 爱好曲线
- `ATTR_MAX` / `ATTR_SOFT_MAX` / `ATTR_BANDS` — 属性尺度与进度条满格线

**门槛怎么标**：单属性专精的理论上限 = 该属性最好的 8 张卡之和 ≈ 32（硬顶 36）。
门槛取这个上限的 60%-85%。改完跑 `python tools/simulate.py --games 3000`，
确认每类结局占 5%-45%、没有死节点。测试里也有一条断言直接算这个上限，
门槛高过它就会挂 —— 这是为了防止「门槛定得根本够不着」（真的发生过）。

### 内容写作

写新内容之前先读 `docs/CONTENT_SPEC.md`（内容作者契约）和 `docs/DESIGN.md`（设计文档，
里面记了二十多个踩过的坑）。内容文件都在导入时自校验，写错会立刻报错并指出问题，
不会拖到运行时。

## 已知边界

- 只做了 Windows 包，Mac/Linux 没打包（Ren'Py 本身支持，改 `tools/build.ps1` 的 `-Package` 就行）。
- **只发绿色包，没有安装程序**。所以没有开始菜单项、没有自动卸载入口 —— 想卸载就删文件夹。
  这是刻意的：未签名的安装 exe 会招来安全软件盘问，绿色包没有这些环节。
- 没有音乐音效，接口留着。
- 没有成就系统，只有结局标签。
- **心理韧性在大多数局里会顶到上限**：它是支撑型属性，没有任何结局门槛引用它，
  而带它的卡占了卡池的一半（休息、娱乐、运动、爱好几乎都给）。这是刻意的 ——
  它只影响疲劳恢复和结局标签，不影响赛道取舍。结局门槛引用到的 8 个属性
  饱和度最高只有 44%。
- 学校名是抽象的「某 985 大学」，专业名可以开局自选。要改成实名，改 `game/core/config.py`
  的 `GameConfig.school_name` 默认值。
